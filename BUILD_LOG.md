## 2026-09-10: Model-Proposing Agent Added (SPEC-002 / DECISION-027)

- Scope: Adds `finne/agent.py` and `tests/test_agent.py`; wires an opt-in `--agent=model` flag into both session scripts. Amends `SPEC-001` sections 9 and 15, `PREREQ-003` sections 6 and 17, `ARCHITECTURE.md`, and `DECISION-023`'s declared dependency list by one entry.
- Why: Arko asked, unprompted, where the AI agent was. There was none. `scripts/session1.py` line 87 read `proposal = build_proposal(owner_policy.max_amount)` — the "agent" proposed the owner ceiling because the script handed it the ceiling — and no model existed anywhere in the runtime. The product's claim is that an agent asks for more than it has earned and that Finné Memory bounds it; a hardcoded constant cannot overreach. The full rules register was re-read first: **no event rule requires a model**, and the 40% memory gate was already satisfied. The defect was an overclaim — the documents said "the agent proposes 25,000" against a line that hardcodes it.
- What was built: the agent is given an opportunity and its available capital and decides two things — how much to commit and how it rates the counterparty. The five fact dimensions are pinned to the opportunity as single-member schema enums, because they identify WHICH opportunity it is rather than what the agent judges about it. It returns a `Proposal` and nothing else.
- **The boundary that makes it honest:** the agent is never given the owner ceiling, any precedent, or any authority value, and cannot go looking. `finne/agent.py` has no import path to `finne/authority/`, `finne/memory/`, `finne/policy.py`, or `finne/base/`, enforced over the transitive closure. `DEMO_AVAILABLE_CAPITAL` is read from `finne/demo_config.py`, never from the owner policy — the two are numerically equal in this corpus and derived from independent places, and a test asserts the request body mentions no ceiling, precedent, or authority value.
- Why this does not reopen the seam (e) finding: what was removed on 2026-09-05 was model-written PROSE asserting things about a decision, which four review rounds each found a new way to make false. What is added is a model-produced PROPOSAL that the deterministic engine then bounds. A proposal cannot be false — only unreasonable — and an unreasonable proposal is the input this product exists to constrain. `finne/explain.py` remains deterministic and loses the model-call permission it never exercised.
- Provider: OpenRouter, single JSON POST, no SDK. `provider: {"require_parameters": true}` is sent on every request and is load-bearing, not decoration: OpenRouter routes one model across several providers and its own documentation states some "treat it as a strong hint" rather than enforcing the schema — on a recorded demonstration that is a failure with no recovery. The default model slug `anthropic/claude-opus-5` and its structured-output support were verified against OpenRouter's live `/api/v1/models` endpoint rather than assumed.
- Dependency: `requests>=2.31` declared explicitly. Not a new installation — it was already present transitively via `web3` and `py-solc-x`. Stdlib `urllib` was tried first and **failed certificate verification on this machine** (no default CA bundle), which is why the spec's original "no new package dependency" claim was corrected in place rather than left standing.
- Failure handling: `AgentUnavailableError` (nothing was proposed) is kept distinct from `AgentResponseError` (a response arrived, unusable). Every failure path raises and is shown on screen; **there is deliberately no fallback to a fixed proposal**, because a silent fallback would make the demonstration appear to work while proving nothing about the agent. A test enumerates six broken-response shapes and asserts none returns a `Proposal`.
